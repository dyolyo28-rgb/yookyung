# 한유경 포트폴리오 웹사이트

현재 공개 중인 포트폴리오의 코드와 이미지·폰트 파일입니다.
배포 버전: 26 / 소스 커밋: 4e81d491a62c0e1aa2a96bfa9311a5c9adba852f

## 파일 구성

- index.html: 웹페이지 구조, CSS 스타일, JavaScript 인터랙션
- assets/: 이미지, SVG 모션, 폰트
- .nojekyll: GitHub Pages에서 정적 파일을 그대로 제공하기 위한 파일

## 실행

압축을 풀고 index.html을 브라우저에서 열면 됩니다.
별도의 설치나 빌드 과정은 없습니다.
index.html과 assets 폴더는 같은 위치에 두세요.

## GitHub Pages에 올리기

이 폴더의 내용물(index.html, assets, .nojekyll)을 저장소의 최상위에 올려주세요.
assets 폴더 안의 파일 구조와 이름을 유지해야 이미지와 폰트가 정상적으로 표시됩니다.
웹사이트 주소는 GitHub Pages 설정에서 확인할 수 있습니다.

## Netlify에 올리기

index.html이 들어 있는 이 폴더를 Netlify Drop에 올리면 됩니다.

## 수정

메모장이나 VS Code에서 index.html을 열어 수정할 수 있습니다.
CSS는 <style> 안에, 인터랙션 코드는 <script> 안에 들어 있습니다.
외부 호스팅으로 옮긴 뒤에는 수정한 파일을 해당 호스팅에도 다시 올려야 반영됩니다.
